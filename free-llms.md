# Free LLMs for a Python practice class

For a class in Russia, plan on tools that open without a VPN. ChatGPT, Claude, and Gemini are free in many countries, but they usually return a region block from a Russian IP, so they are a bad default for the lesson.

Limits below are what vendors publish or what recent checks report. Free caps change often. Test the shortlist on a school computer the morning of class.

Checked around 1–3 October 2026. Access can change.

## Use these in class (Russia, no VPN)

| Tool | Link | Registration | Limits | Russia without VPN | Good for Python? |
|---|---|---|---|---|---|
